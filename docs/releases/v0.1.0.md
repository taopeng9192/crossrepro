# CrossRepro v0.1.0

CrossRepro turns a failing CLI, build or test command into a privacy-safe,
portable reproduction with deterministic `REPRODUCED`, `NOT_REPRODUCED` or
`ENVIRONMENT_BLOCKED` verdicts.

## Included

- Capture of command output, exit code and a minimised environment snapshot.
- Deterministic redaction and a fail-closed portable bundle with manifest and
  SHA-256 verification.
- A validated `repro.yml` v1 protocol, replay engine and GitHub Actions
  workflow generator.
- Three runnable examples, including a deliberate Windows versus POSIX shell
  difference.

## Validation

The pre-release baseline passed all six GitHub-hosted Windows, Ubuntu and macOS
jobs for Python 3.10 and 3.12. Each artifact reports 112 tests with zero
failures/errors, three examples, bundle privacy scanning, checksum verification,
wheel construction and a clean wheel installation. See `VALIDATION_REPORT.md`
and the repository Actions page for the version-commit run.

## Install

Download `crossrepro-0.1.0-py3-none-any.whl` from this release, then run:

```text
python -m pip install crossrepro-0.1.0-py3-none-any.whl
crossrepro --help
```

The release does not publish to PyPI. Review a reproduction artifact before
sharing it: redaction is deterministic and fail-closed for detected high-risk
content, but it cannot prove recognition of every possible secret format.
