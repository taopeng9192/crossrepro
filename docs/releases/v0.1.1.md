# CrossRepro v0.1.1

## Fixed

`collect --timeout` now has bounded Windows cleanup when a detached child keeps
inherited stdout/stderr pipe handles open. It returns sanitized timeout evidence
for manual review instead of waiting indefinitely.

## Validation

The release is gated by the Windows, Ubuntu and macOS GitHub Actions matrix for
Python 3.10 and 3.12. The timeout cleanup has dedicated regression coverage.

## Install

Download `crossrepro-0.1.1-py3-none-any.whl` from this release, then run:

```text
python -m pip install crossrepro-0.1.1-py3-none-any.whl
crossrepro --help
```

The release is distributed through GitHub Release assets, not PyPI.
